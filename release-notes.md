4x texture pack for Banjo-Tooie Recompiled with an Original / Upscaled 4x toggle.

Download **BanjoTooie-Upscaled-4x-1.0.0.zip**, extract it, and read `README.txt` before installing. The accompanying `.sha256` file verifies the ZIP.

**Requires a runtime with RT64 texture-pack support. Stock Windows x64 v1.0.1 does not have that registration.** Tested with the local 1.0.1+textures build. Compatibility source and build instructions are included; a prebuilt runtime and executable-patching installer are not included. Players need their own existing game installation and supported ROM.

On a compatible runtime, copy the intact `.rtz` to `%LOCALAPPDATA%\BanjoTooieRecompiled\mods\`, then enable it in Mods. Open Configure ? Texture quality to choose Original or Upscaled 4x.

Includes 11,033 upscaled source textures and 15,119 hash mappings. Runtime validation covers the attract sequence, not a full playthrough. Unmapped textures retain their original rendering.
